module notebook_models

doukimd.notebook_models

Source: src/doukimd/notebook_models.py:1

Typed projections of validated notebook cells and saved outputs.

Classes

  • CellMetadata — Standard cell tags that control published input and output.

  • CodeCell — Literal code and its existing outputs.

  • ErrorOutput — A recorded exception rendered without executing its traceback.

  • MarkdownCell — Markdown prose with optional embedded image attachments.

  • Notebook — A nonexecuting projection of a version four notebook.

  • NotebookValue — Project relevant fields after validation against nbformat's schema.

  • RawCell — Raw notebook cells retained as escaped text.

  • RichOutput — A display or expression result containing alternative MIME formats.

  • StreamOutput — Saved stdout or stderr from a code cell.
