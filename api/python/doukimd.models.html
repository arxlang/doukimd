Classes

  • ApiSettings — API source discovery and virtual reference pages.

  • ApiSymbol — An API declaration and its validated Douki documentation.

  • ApiVariant — A statically collected callable signature and its own prose.

  • Config — Version one project configuration.

  • NavEntry — A local page, external URL, nested group, or generated API tree.

  • NavigationItem — A route-aware menu entry with nested pages or flat API sections.

  • NavigationSettings — Ordered navbar links and independently scoped documentation menus.

  • Page — An authored or virtual page.

  • PageSettings — Front matter supported on authored Markdown pages.

  • ProjectSettings — Project metadata available to content templates.

  • PythonSource — Configure static collection of explicitly selected Python modules.

  • SearchSettings — Local full-text search over authored, notebook, and API content.

  • Settings — Reject unknown settings and implicit value coercion.

  • SidebarSettings — A named menu selected by route prefixes or page front matter.

  • SiteBuild — A complete validated site ready to write.

  • SiteSettings — Site presentation settings.

  • ThemeSettings — Frontend framework, color preference, and local template overrides.
