Contributing

Use Python 3.10–3.14 and Poetry 2:

poetry install
poetry run pre-commit install
poetry run makim all.ci
poetry check --lock

Update dependencies using poetry lock, never by editing the lockfile. Douki docstrings must be synchronized and idempotent:

poetry run douki sync src tests examples/basic/src
poetry run douki check src tests examples/basic/src

The Makim groups, hooks, and release configuration are adapted from Douki, commit f77adee49546d4ea8e95ced671d470379c5bd741. The BSD license and upstream attribution are retained. Documentation is built with DoukiMD. Publication is never triggered by pull requests.

Publish the documentation

After merging documentation changes, run the Documentation workflow manually from upstream main. It builds the site and publishes the documentation artifact to the gh-pages branch. Push and pull-request runs only build and validate the documentation.

After the first manual run creates gh-pages, configure Settings → Pages to Deploy from a branch, selecting gh-pages and / (root). The publishing action adds .nojekyll for the generated static site.
